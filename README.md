# Cafe-origen
Cafetería-Portfolio
Sitio web de una cafetería, con diseño responsive y un carrusel de imágenes interactivo. Proyecto de práctica hecho para mi portfolio — es mi primer trabajo de desarrollo web pensado para mostrarle a clientes.

## 🔗 Demo en vivo
https://cafeteriaorigen.netlify.app

## 🛠️ Tecnologías
- HTML5
- CSS3 (variables, Grid, Flexbox)
- JavaScript vanilla (sin frameworks ni librerías)

## ✨ Funcionalidades
- Diseño totalmente responsive (mobile, tablet, desktop)
- Navegación por anclas dentro de la misma página (sin recargar)
- Carrusel de imágenes que se desliza solo al pasar el mouse por los bordes
- Header sticky con efectos hover
